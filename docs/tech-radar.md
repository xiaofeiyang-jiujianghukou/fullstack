## 性能与内存速览（初始认知）

- **JVM（Java）**：JIT 预热后吞吐第一梯队；GC 需要理解与调优；内存基线高（堆 + Metaspace + 线程栈），容器内必须显式设限；Java 21 虚拟线程改善高并发 IO。
- **Node.js**：事件循环 + 单线程模型，IO 密集强、CPU 密集弱（需 worker threads 或拆服务）；默认堆上限需留意（`--max-old-space-size`）；内存占用中等。
- **Go**：编译为单二进制，goroutine 轻量并发；GC 以低停顿为设计目标、可调项极少；内存占用低，云原生与边缘部署首选。
- **Python**：GIL 限制 CPU 并行（free-threading 仍在演进）；解释执行慢，性能依赖 C 扩展与异步框架；内存中等但精细优化空间小。

## 选型的宏观维度

评估任何一条路线时统一过这几个维度，结论按维度记入各路线 `evaluation.md`：

1. 团队技能与招聘市场
2. 业务复杂度与领域建模需求
3. 性能画像：IO 密集 / CPU 密集 / 延迟敏感
4. 内存与部署约束：容器规格、Serverless、边缘
5. 生态成熟度与第三方库质量
6. 迭代速度与长期维护成本的权衡
